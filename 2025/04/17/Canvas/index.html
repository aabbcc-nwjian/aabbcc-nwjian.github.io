Canvas

<canvas> 是 HTML5 引入的一个元素，用于在网页上绘制图形。它提供了一个可以通过 JavaScript 进行绘图的 API，使得开发者能够动态生成图像、动画、游戏等内容。

绘制基本图形

绘制直线

使用 moveTo(x1,y1) 和 lineTo(x2,y2) 方法来绘制直线。moveTo 方法用于设置线条的起始点，lineTo 方法用于设置线条的结束点。然后可以使用 stroke() 方法来绘制线条。

其他方法

  • closePath() : 关闭当前路径，会尝试从当前点绘制一条线回到路径的起始点
  • fill() : 填充路径所包围的区域

绘制矩形

使用 strokeRect(x,y,width,height) 方法可以绘制一个矩形边框,使用 fillRect(x,y,width,height) 方法可以绘制一个填充的矩形

strokeRect()和fillRect()均需要4个参数，前两个为矩形左上角点的横纵坐标，后两个为矩形的宽高。

绘制圆形

通过使用 arc(x,y,radius,startAngle,endAngle,anticlockwise) 方法来绘制圆形。其中 x 和 y 是圆心的坐标，radius 是半径，startAngle 和 endAngle 是起始角度和结束角度（以弧度为单位），anticlockwise 是一个布尔值，表示是否逆时针绘制。

Math.PI _ 2表示绘制的圆心角为2pai，通过修改Math.PI _ 2可绘制出圆弧和扇形。

绘制文本

Canvas 提供了两个主要方法来绘制文本：

  • **fillText(text, x, y)**：绘制填充文本。
  • **strokeText(text, x, y)**：绘制描边文本（文本边框）。

绘制图像

可以使用 drawImage() 方法在 Canvas 上绘制图像。
ctx.drawImage(image, x, y, width, height)

通过drawImage(image, sx, sy, sWidth, sHeight, dx, dy, dWidth, dHeight)，我们可以从源图像中截取一部分（由 sx, sy, sWidth, sHeight 指定），并在目标位置（dx, dy）绘制，同时可以指定目标宽度和高度（dWidth, dHeight）进行缩放。

颜色

填充和描边

与文本类似，canvas使用 fillStyle 属性来设置图形的填充颜色，使用 strokeStyle 属性来设置图形的描边颜色

渐变

线性渐变 (createLinearGradient)

  • 使用 createLinearGradient(x0, y0, x1, y1) 方法创建线性渐变对象。该方法接受四个参数，表示渐变的起点 (x0, y0) 和终点 (x1, y1)。

  • 使用 addColorStop(position, color) 方法为渐变对象添加颜色停止点。position 是一个介于 0 到 1 之间的值，表示颜色在渐变中的位置；color 是一个表示颜色的字符串。

  • 将渐变对象赋值给 fillStyle 或 strokeStyle，然后绘制图形或文本。

径向渐变 (createRadialGradient)

径向渐变是从一个圆心向外扩散的渐变方式。
使用 createRadialGradient(x0, y0, r0, x1, y1, r1) 方法创建径向渐变对象。该方法接受六个参数，分别表示两个圆的圆心和半径：

  • (x0, y0, r0)：起始圆的圆心和半径。

  • (x1, y1, r1)：结束圆的圆心和半径。
    与线性渐变类似，使用 addColorStop(position, color) 方法为径向渐变添加颜色停止点。

阴影

canvas可以根据以下属性的值自动为已有形状或路径生成阴影。

  • shadowColor：CSS 颜色值，表示要绘制的阴影颜色，默认为黑色。

  • shadowOffsetX：阴影相对于形状或路径的 x 坐标的偏移量，默认为 0。

  • shadowOffsetY：阴影相对于形状或路径的 y 坐标的偏移量，默认为 0。
    *shadowBlur：像素，表示阴影的模糊量。默认值为 0，表示不模糊。

    图像混排模式

    在 Canvas 中，图像混排模式（也称为 全局合成操作）决定了如何将新绘制的图形与已有内容进行混合。Canvas 提供了 26 种混排模式，通过 globalCompositeOperation 属性来设置。这些模式可以用于实现各种视觉效果，如遮罩、叠加、擦除等。

    模式 解释
    默认模式
    source-over 新图形绘制在现有内容之上
    覆盖模式
    source-in 只绘制新图形与现有内容重叠的部分
    source-out 只绘制新图形与现有内容不重叠的部分
    source-atop 新图形只绘制在现有内容之上，且仅重叠部分可见
    目标模式
    destination-over 新图形绘制在现有内容之下
    destination-in 只保留现有内容与新图形重叠的部分
    destination-out 只保留现有内容与新图形不重叠的部分
    destination-atop 现有内容只保留与新图形重叠的部分，新图形绘制在现有内容之上
    清除模式
    lighter 新图形与现有内容的颜色值相加，产生更亮的效果
    copy 只绘制新图形，完全忽略现有内容
    xor 新图形与现有内容重叠的部分变为透明
    混合模式
    multiply 新图形与现有内容的颜色值相乘，产生更暗的效果
    screen 新图形与现有内容的颜色值取反后相乘，再取反，产生更亮的效果
    overlay 结合 multiply 和 screen，根据底色决定使用哪种模式
    darken 取新图形与现有内容的较暗颜色
    lighten 取新图形与现有内容的较亮颜色
    color-dodge 通过降低对比度使底色变亮以反映新图形
    color-burn 通过增加对比度使底色变暗以反映新图形
    hard-light 根据新图形的颜色决定使用 multiply 或 screen
    soft-light 类似于 hard-light，但效果更柔和
    difference 取新图形与现有内容的颜色差值
    exclusion 类似于 difference，但对比度更低
    hue 使用新图形的色相，保留现有内容的饱和度和亮度
    saturation 使用新图形的饱和度，保留现有内容的色相和亮度
    color 使用新图形的色相和饱和度，保留现有内容的亮度
    luminosity 使用新图形的亮度，保留现有内容的色相和饱和度

变换与状态管理

Canvas 提供了多种变换方法，如平移、旋转、缩放等。还可以使用 save() 和 restore() 方法来保存和恢复画布的状态。

平移

使用 translate(x, y) 方法可以将坐标原点移动到指定的位置，从而实现图形的平移。x 和 y 分别表示在 x 轴和 y 轴上的位移量

旋转

使用 rotate(angle) 方法可以将图形围绕坐标原点旋转指定的角度。角度以弧度为单位。

缩放

使用 scale(xScale, yScale) 方法可以对图形进行缩放。xScale 和 yScale 分别表示在 x 轴和 y 轴上的缩放比例

平移、旋转、缩放等变换都是对坐标轴的变换，并不是直接改变图形

动画

Canvas实现动画效果的方法是将动画的一帧帧绘制出来，绘制新图案的同时删除上一个图案。通常使用 requestAnimationFrame 或setInterval()来实现平滑的动画。

requestAnimationFrame
requestAnimationFrame 是一个浏览器提供的 API，它可以在浏览器下一次重绘之前调用指定的函数。与传统的定时器（如 setInterval 和 setTimeout）相比，requestAnimationFrame 可以更好地控制动画的帧速率，并且更加高效，因为它会根据浏览器的刷新频率自动调整帧速率，从而避免了不必要的重绘

鼠标事件

Canvas 可以响应各种鼠标事件，如 click（点击）、mousedown（鼠标按下）、mouseup（鼠标松开）、mousemove（鼠标移动）等。可以通过给 canvas 元素添加事件监听器来处理这些事件。

获取鼠标位置后就能根据鼠标位置设置图形对应的变换，从而实现点击、拖拽、悬停等功能。

总结

<canvas> 是一个强大的工具，可以用于在网页上绘制各种图形和动画。通过 JavaScript 的 API，开发者可以灵活地控制画布上的每一个像素，实现复杂的视觉效果。无论是简单的图形绘制，还是复杂的游戏开发，Canvas 都是一个非常实用的选择。
