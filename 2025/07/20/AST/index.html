AST

概念

AST：Abstract Syntax Tree（抽象语法树） ,是源代码语法结构的一种抽象表示，它以树状的形式表现编程语言的语法结构，树上的每个节点都表示源代码中的一种结构。

常用于代码语法的检查、代码风格的检查、代码的格式化、代码的高亮、代码错误提示、代码自动补全等等场景

AST 的核心特点

  • 树状结构：每个节点代表代码中的一个构造（如表达式、语句等）
  • 忽略细节：不保留空格、注释、分隔符等非逻辑元素
  • 语言无关：不同语言有不同的 AST 规范（如 JavaScript 使用 ESTree）

AST 的生成过程

生成 AST 的过程主要分为 词法分析 (Lexical Analysis) 和 语法分析 (Syntax Analysis)

1.词法分析阶段（Lexical Analysis）

核心任务

将源代码字符流转换为有意义的 词法单元（tokens），每个 token 包含：

  • 类型（关键字/标识符/运算符等）
  • 值（具体的字符内容）
  • 位置信息（行号、列号）

JavaScript 关键 Token 类型

Token 类型 示例 描述
Identifier sum, a 变量名/函数名
Keyword const, function 语言关键字
Punctuator =, +, => 运算符和标点符号
NumericLiteral 42 数字字面量
StringLiteral "hello" 字符串字面量

2.语法分析阶段（Syntax Analysis）

核心任务

根据语言的语法规则，将 tokens 组织成 树形结构。关键过程：

  1. 语法规则匹配：使用上下文无关文法（CFG）验证结构

  2. 节点生成：为每个语法结构创建 AST 节点

  3. 错误恢复：遇到错误时尝试继续解析

关键节点类型解析

1. Program 节点

  • 根节点，表示整个程序

  • body 包含所有顶层语句

2. VariableDeclaration 节点

  • kind：声明类型（var/let/const）

  • declarations：变量声明器列表

3. VariableDeclarator 节点

  • id：被声明的标识符

  • init：初始化表达式

4. ArrowFunctionExpression 节点

  • params：参数列表

  • body：函数体（可能是块语句或表达式）

  • expression：是否为简写形式（无大括号）

5. BinaryExpression 节点

  • 表示二元运算（加减乘除等）

  • operator：运算符类型

  • left/right：左右操作数

AST 在 Babel 中的应用

Babel 是一个JavaScript编译器，其核心工作流程完全基于 AST 操作

Babel 中常用到的功能包：

@babel/core：Babel 编译器本身，提供了 babel 的编译 API；
@babel/parser：将 JavaScript 代码解析成 AST 语法树；
@babel/traverse：遍历、修改 AST 语法树的各个节点；
@babel/generator：将 AST 还原成 JavaScript 代码；
@babel/types：判断、验证节点的类型、构建新 AST 节点等。

Babel 的处理流程

  1. Parse：通过 @babel/parser 将源代码转换为 AST,这个过程要经词法分析、语法分析、构建AST（抽象语法树）一系列操作；

  2. Transform：通过 @babel/traverse 遍历并修改 AST,按照编译器指定的规则进行处理，形成一个新的表现形式；

  3. Generate：通过 @babel/generator 将 AST 转化为新的代码

常见应用场景

1. 语法转换（ES6+ → ES5）

2. 代码分析

3. 代码修改/优化
