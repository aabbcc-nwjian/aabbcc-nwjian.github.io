大模型调用

概述

在当今的AI应用开发中，大语言模型（LLM）已成为核心技术之一。在应用开发中调用大模型的三种主要方式：API调用、本地部署。

一、API调用

API调用是指通过网络请求访问云服务商提供的大模型服务，无需在本地部署模型。这是最基础、最直接的调用方式。模型提供商（如 OpenAI, ModelScope, 百度）会提供标准的 HTTP API。

API调用示例

ModelScope平台

工作原理：你的应用程序向模型的 API 端点发送一个 HTTP 请求（通常是 POST），请求体中包含了提示词、参数等，然后接收并解析返回的 JSON 响应。

关键步骤

1. 认证机制

2. 请求优化

3. 错误处理和重试机制

优缺点

  • 优点：简单、直接、性能好。

  • 缺点：功能相对单一，处理复杂逻辑（如使用工具、多步骤推理）需要自己编写大量代码。

二、本地部署方式

为了简化 API 调用和实现更复杂的功能，社区和厂商提供了各种 SDK 和框架。本地部署是将大模型完全部署在自己的服务器或本地环境中，提供完全的数据控制和定制能力。

部署架构

1. 单机部署

2. 分布式部署

高级框架：如 LangChain 和 LlamaIndex。

LangChain：是一个用于开发由 LLM 驱动的应用程序的框架。它的核心思想是让模型能够“链式”调用其他资源或动作。

  • 核心概念：

    • 链：将多个组件（模型调用、数据查询、工具使用）按顺序组合起来，完成复杂任务。
    • 代理：让模型自主决定调用哪些工具（如计算器、搜索引擎、数据库）来完成任务，实现“推理-行动”循环。
    • 记忆：管理对话历史，实现多轮对话。

  • 适用场景：构建复杂的、有状态的、需要与外部数据或工具交互的 AI 应用。

LlamaIndex：专注于数据接入框架，主要解决如何让 LLM 高效地查询和利用你的私有数据。

  • 核心概念：将外部文档（PDF、Word、数据库等）通过索引（向量索引、关键词索引等）结构化和检索，然后与大模型结合，实现基于私有知识的问答。

  • 适用场景：构建企业知识库问答、文档摘要等。

三、流式传输

流式传输 是指大模型在生成文本时，不是等待整个响应完全生成后再一次性返回，而是每生成一个token（可能是字、词或子词）就立即返回给前端。

实现原理

1.大模型处理

大模型的核心是一个自回归生成的过程。这意味着模型是逐个预测下一个最可能的token的。

  1. 处理用户输入： 首先，模型将用户的整个输入（Prompt）进行处理，编码成一系列的向量表示。

  2. 开始生成第一个Token： 模型基于整个输入上下文，计算出一个概率分布，从中选择（通过采样或贪婪解码）最可能的下一个Token（比如”你”字）。关键点来了： 在流式模式下，这个Token一旦生成，并不会留在模型里等待后续内容，而是会通过一个流式响应接口立即发送给前端。

  3. 循环生成： 接下来，模型将刚才生成的Token（”你”）作为新的输入，与之前的上下文拼接起来，再预测下一个Token（比如”好”字）。生成后，再次立即发送。

  4. 持续直到结束： 这个过程不断重复，直到模型生成一个特殊的结束符（如<eos>），表示生成完成。

2.前端实现

前端负责接收这些持续不断的数据块，并将其流畅地展示给用户。

  1. 建立连接： 前端使用 EventSource 或 Fetch API 向服务器的流式端点发起请求。

  2. 监听数据流：

    • 使用 EventSource：它会自动监听 message 事件，每当服务器发送一个新的数据块，就会触发此事件。
    • 使用 Fetch API：通过读取返回的 response.body（一个ReadableStream），可以不断地从流中读取数据。

  3. 实时渲染： 每当收到一个数据块（如一个”你”字），JavaScript就会将其追加到网页的DOM元素（如<div>）中。这就像是有人在不停地打字。

关键技术：Server-Sent Events (SSE)

在Web开发中，实现这种服务器向客户端”推送”数据的技术，最常用的就是 **Server-Sent Events (SSE)**。

  • 格式： 数据以特定的文本格式流式传输，每个消息由 data: 开头，后跟实际数据，并以两个换行符 \n\n 结束。

  • 优点： SSE是基于HTTP的简单协议，使用方便，浏览器原生支持（通过EventSource）。

四、模型微调

微调是指在一个已经预训练好的大模型（例如，已经在万亿级通用文本上学习过的模型）的基础上，使用特定领域或任务的、规模较小的数据集，对模型的参数进行额外的训练。

为什么需要微调

  • 领域适配：让通用模型适应特定行业领域
  • 任务定制：优化模型在特定任务上的表现
  • 风格学习：学习特定的语言风格或格式要求
  • 知识注入：注入新的专业知识

微调方法

1. 全参数微调（Full Fine-tuning）

这是最直接的方法，使用数据集，对预训练模型的所有参数（权重）进行更新。

2. 参数高效微调（PEFT）

这是当前的主流和未来趋势，它只更新模型的一小部分参数，从而大幅降低成本。
